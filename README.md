# BrainHub

あなた専用の第二の脳 — AIを使ったメモ・記憶管理アプリ

## 概要

BrainHub は、ワークスペースごとにメモを書き溜め、後から自然文で検索・質問できるパーソナルメモアプリです。

- **ワークスペース**: カテゴリ（仕事・学校・旅行・アイデアなど）ごとにメモを整理
- **メモ**: タイトル・本文を記録し、キーワードから自動でタグ付け
- **検索**: 保存したメモをキーワードで横断検索

## 現在の実装

MVP として、ブラウザの `localStorage` にすべてのデータを保存する静的サイト版を実装しています。バックエンドやアカウント機能はまだありません。

- `index.html` — 画面構成
- `style.css` — スタイル（ライト/ダークテーマ対応）
- `app.js` — メモ・ワークスペースの CRUD、検索ロジック

## ローカルでの動作確認

ビルド不要の静的サイトです。`index.html` をブラウザで開くか、簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```
